Бот проходит по всему рынку BingX (perpetual), находит **зоны спроса и предложения** на старшем таймфрейме, оценивает каждую зону скорингом и ждёт возврата цены с подтверждающим **пинбаром на 5m** внутри зоны. При срабатывании присылает сигнал в Telegram с нарисованным графиком (свечи, зоны, выделенная сигнальная область), уровнями входа и стопа.

Это **сигнальный инструмент**: ордера на бирже он не выставляет — только находит сетап и присылает уведомление. Решение о входе принимаете вы.

## Как это работает (кратко)

1. **Зона рождается из разворотной свечи.** На старшем ТФ (`ZONE_TF`) кандидаты на базу зоны — бычий/медвежий пинбар или поглощение. Пинбар формализован: тело ≤ 30% диапазона, хвост ≥ 2× тела, встречный хвост ≤ 0.5× тела.
2. **Геометрия зоны** — от экстремума свечи до основания тела, с ограничением размера `≤ MAX_ZONE_ATR × ATR` (адаптивно к волатильности).
3. **Скоринг зоны числом:** сила импульса после зоны в единицах ATR (`move / ATR`) + плотность свечи (`body / range`) + swing-подтверждение. В работу идут только зоны со скором `≥ MIN_ZONE_SCORE`. Слабый импульс (`< IMPULSE_MIN_ATR`) отбраковывает зону сразу.
4. **Жизненный цикл зоны:** пробитые зоны инвалидируются (по закрытию или тени — `INVALIDATION_METHOD`), отработавшая зона помечается одноразовой, в работу берутся только 2 ближайшие к цене зоны каждого типа.
5. **Мультитаймфрейм-вход:** зона задаёт «где», а вход — по пинбару на 5m внутри зоны («когда»). Стоп — за экстремумом сигнальной 5m-свечи, вход — по текущей цене возврата.
6. **Async-скан всего рынка:** все тикеры обрабатываются параллельно под семафором `MAX_CONCURRENT`, полный проход повторяется каждые `SCAN_INTERVAL_SEC`.

```python

```

Основные параметры стратегии:

| Параметр | Значение | Смысл |
|---|---|---|
| `ZONE_TF` | `"15m"` | таймфрейм поиска зон (можно ставить `4h` и др.) |
| `ZONE_LIMIT` | `1000` | сколько свечей грузить для поиска зон |
| `ATR_PERIOD` | `20` | период ATR (среднее TR) |
| `MIN_ZONE_SCORE` | `4` | порог скора зоны (↓ больше зон / ↑ строже) |
| `IMPULSE_MIN_ATR` | `2` | мин. импульс после зоны, в ATR |
| `MAX_ZONE_ATR` | `4` | ограничение высоты зоны, в ATR |
| `ZONE_TOLERANCE` | `0.003` | допуск на вход цены в зону (0.3%) |
| `INVALIDATION_METHOD` | `"close"` | инвалидация зоны: `close` или `wick` |
| `MAX_ZONES` | `10` | макс. зон на тип (supply/demand) |
| `SCAN_INTERVAL_SEC` | `300` | пауза между полными сканами рынка, сек |
| `MAX_CONCURRENT` | `10` | одновременных обработок символов |
| `CHART_CANDLES` | `200` | сколько свечей рисовать на графике |

## Формат сигнала

В Telegram приходит скрин графика (свечи + зоны + выделенная сигнальная область) и подпись:

```
🚨 SYMBOL Short Signal
TF: 4h (Pinbar on 5m)
Zone: 108.580000 - 109.270000
Current price: 108.290000
Entry: 108.290000
Stop: 108.490000
```

Сигнал даёт **вход и стоп**; тейк-профит в сигнал не входит — цель определяйте сами по ближайшей противоположной зоне или структуре.
